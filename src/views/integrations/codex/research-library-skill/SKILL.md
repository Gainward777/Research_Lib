# Research Library

Search the library before repeating research on a known topic. Save durable final results,
including negative results, but do not save routine progress, secrets, checkpoints, full logs,
or authoritative experiment state.

Use a stable idempotency key when retrying a write. Experiment reports must include experiment ID,
iteration ID, code revision, parameter summary, conclusions, limitations, and selected final artifacts.
